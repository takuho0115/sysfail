# sysfail (English)

sysfail is a game for practicing Linux incident response: each level breaks a small set of servers, and you investigate and fix them from a shell.

- [Level guides](guides/index.md): what to check first, and why, for some levels. They contain hints toward the solution.
- [Custom levels](../ja/custom-levels/index.md): how to build your own level (Japanese only).

Installation, requirements, and how to verify the downloads are covered in Japanese: [requirements](../ja/requirements.md), [installation](../ja/install/index.md), [verifying the downloads](../ja/verify.md), [playing](../ja/play.md), and [troubleshooting](../ja/troubleshooting.md). Download the binaries from [Releases](https://github.com/takuho0115/sysfail/releases), report bugs in [Issues](https://github.com/takuho0115/sysfail/issues/new/choose), and ask questions in [Discussions](https://github.com/takuho0115/sysfail/discussions).
