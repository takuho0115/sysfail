# PF-17 Isolation test {#pf-17}

Help for item PF-17 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Isolation breached {#breached}

Traffic from the level's internal network reached outside or the host. This docker cannot contain the level safely, so startup stops. Roll docker Engine back to a reviewed version or wait for a fix, and report it on GitHub Issues if you can reproduce it.

## Host listeners are reachable {#reached}

Containers reached services listening on this machine. docker does not restrict this, so block it with the [PF-14 firewall examples](pf-14.md#firewall). The game still starts.

## Cannot be determined {#undetermined}

- Timeout: docker is busy. Try again after other work finishes.
- Missing image: the first preparation builds it. Start a game once, then run `sysfail doctor` again.
- Other: check docker with `docker info` and try again.

## Cannot run or observe on the daemon side {#daemon-side}

Check docker's state and try again. On macOS, restart colima (`colima restart -p sysfail`) and recreate the sysfail profile.
