# PF-13 Firewall method {#pf-13}

Help for item PF-13 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## iptables and nftables mixed {#mixed}

With rules in both, it is hard to tell which applies. The checks read both. Confirm the setup with `sudo iptables -S` and `sudo nft list ruleset`.
