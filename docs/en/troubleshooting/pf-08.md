# PF-08 docker data free space {#pf-08}

Help for item PF-08 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Low free space {#low}

Levels need 10GB or more for images and containers. Removing unused images and containers frees space:

```bash
docker system df
docker system prune
```

`docker system prune` removes stopped containers and unused images and networks. Check first that nothing you need is removed.

## WSL2 disk {#wsl2}

The WSL2 disk is a vhdx file on a Windows drive. If its maximum size exceeds the drive's free space, Windows runs out first even though WSL looks fine. Set the maximum size (for example `defaultVhdSize` in `.wslconfig`) below the drive's free space.

## macOS (colima) disk {#macos}

Both the colima VM disk and the Mac volume holding it need free space. If the VM disk is larger than the Mac's free space, the Mac fills up first. Recreate the sysfail profile with a smaller disk (`colima delete -p sysfail`, then `colima start -p sysfail --disk <GB>`).
