# PF-14 Host listeners {#pf-14}

Help for item PF-14 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Ports listening on all addresses {#exposed}

Services listening on 0.0.0.0, :: or the game's gateway addresses may be reachable from level containers. Bind them to 127.0.0.1 or block them with the firewall examples below. The game still starts.

## docker API port {#docker-api}

The docker daemon API (2375/2376) is listening on all addresses. Remove `hosts` in `/etc/docker/daemon.json` or the `-H tcp://...` option in the systemd unit.

## Firewall examples {#firewall}

Examples that reject traffic from the docker bridges (docker0, br-*) to the host. The game never adds these rules itself.

- firewalld: `sudo firewall-cmd --permanent --zone=docker --add-rich-rule='rule family=ipv4 reject'`, then `sudo firewall-cmd --reload`
- nftables: add `iifname "docker0" reject` and `iifname "br-*" reject` to `inet filter input`
- iptables: `sudo iptables -A INPUT -i docker0 -j REJECT` and `sudo iptables -A INPUT -i br+ -j REJECT`
- ufw: `sudo ufw deny in on docker0`

On WSL2, configure this in Linux inside WSL, not on Windows.
