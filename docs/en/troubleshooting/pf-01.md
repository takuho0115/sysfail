# PF-01 docker command {#pf-01}

Help for item PF-01 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## docker command not found {#missing}

The game builds level environments with docker, so it cannot start without the docker command.

- Linux and WSL2: install Docker Engine following your distribution's instructions (for example `docker-ce` from Docker's official repository).
- macOS: install colima and the docker CLI.

Then check that `docker --version` works. If it does not, make sure the directory that holds docker is on your PATH.
