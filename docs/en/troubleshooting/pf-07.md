# PF-07 Container runtime version {#pf-07}

Help for item PF-07 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Vulnerable or old runtime {#denied}

runc and containerd are updated together with docker. Update the docker packages.

## The version cannot be confirmed {#unconfirmed}

This warning appears when the table has no denied versions or the version cannot be read. The game starts. If you keep docker up to date, you can ignore it.
