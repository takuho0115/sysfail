# PF-04 docker Engine version {#pf-04}

Help for item PF-04 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Older than the minimum {#below-floor}

docker Engine older than the minimum is affected by CVE-2024-29018 (external name lookups from internal networks are forwarded to the host). Update to at least the version doctor shows, using your package manager (for example `dnf upgrade docker-ce`).

## A vulnerable version {#denied}

This version has a vulnerability that may let traffic from outside this machine reach the level environment. Update to a version in the range doctor shows (at or above the minimum and outside the excluded range).

## The version cannot be parsed {#unparsable}

Check the output of `docker version`. Development or custom builds may use a different version format.

## Newer than the reviewed range {#newer}

The prerequisite table covers versions up to the one it lists. Newer versions have not been checked for known problems. The game still starts and runs the isolation test ([PF-17](pf-17.md)) right before startup.

## Allowed with --accept-version {#accepted}

You allowed a version the table rejects. Look up why it is rejected (the vulnerability ID) and confirm your environment is not affected.
