# PF-15 Bridge netfilter {#pf-15}

Help for item PF-15 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## net.bridge.bridge-nf-call-iptables=1 {#enabled}

While this is 1, docker's internal-network rules drop packets routed between networks, so levels that route cannot start. Set it to 0 only while you play and always restore it:

```bash
sudo sysctl -w net.bridge.bridge-nf-call-iptables=0
# restore after playing
sudo sysctl -w net.bridge.bridge-nf-call-iptables=1
```

Side effects:

- It applies to the whole host. Isolation within bridges, such as docker's icc=false, stops working.
- On WSL2, it affects every distribution in the same WSL VM.
- Do not change it on a machine running software that expects 1, such as Kubernetes.

## The value cannot be confirmed {#unconfirmed}

When docker runs in another VM or machine, the value cannot be read from this machine. `sysfail doctor --full` starts a check container and reads it on the docker daemon side. If it still cannot be confirmed, run `sysctl net.bridge.bridge-nf-call-iptables` on the machine running the docker daemon.
