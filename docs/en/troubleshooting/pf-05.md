# PF-05 docker compose {#pf-05}

Help for item PF-05 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Missing or too old {#missing}

The game uses `docker compose` (the v2 plugin). The old `docker-compose` (v1) is not supported. Install or update `docker-compose-plugin` from Docker's repository and check with `docker compose version`.
