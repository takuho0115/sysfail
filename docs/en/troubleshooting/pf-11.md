# PF-11 docker endpoint {#pf-11}

Help for item PF-11 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Remote endpoint {#remote}

The game only operates the local docker on this machine. Unset `DOCKER_HOST` or run `docker context use default`.

## Cannot confirm the same machine (macOS) {#unverifiable}

Check that docker points at the sysfail colima socket and that `colima ssh -p sysfail` works. The isolation test does not pass until this is confirmed.
