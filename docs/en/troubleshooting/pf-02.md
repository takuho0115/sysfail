# PF-02 docker daemon {#pf-02}

Help for item PF-02 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Cannot connect to the daemon {#down}

The docker daemon is not running.

- Linux and WSL2: `sudo systemctl start docker` (`sudo systemctl enable docker` to start it at boot)
- macOS: `colima start -p sysfail`

## No permission to use docker {#permission}

On Linux, add your user to the docker group to use docker without sudo:

```bash
sudo usermod -aG docker "$USER"
```

Then log in again. Members of the docker group can effectively act as root, so limit who you add on shared machines.

## The daemon does not respond {#no-response}

docker may not respond in time while other starts or cleanups are running. Try again after they finish. If it keeps happening, check whether `docker info` returns and look for errors in `journalctl -u docker`.

## The state cannot be checked {#other}

Run `docker info` and check the error it shows.
