# PF-03 docker kind {#pf-03}

Help for item PF-03 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Not Docker Engine {#not-engine}

The game relies on how Docker Engine behaves (network rules, image builds). Compatible tools such as Podman do not meet the isolation assumptions, so they are not supported. Install and use Docker Engine.
