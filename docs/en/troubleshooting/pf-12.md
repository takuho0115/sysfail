# PF-12 Network address range {#pf-12}

Help for item PF-12 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Overlaps this machine's routes {#overlap}

The game uses addresses starting at `10.200.0.0` by default. If they overlap your LAN or VPN, traffic mixes. Change the start with `SYSFAIL_SUBNET_BASE`:

```bash
export SYSFAIL_SUBNET_BASE=10.120.0.0
```

The value must be inside `10.0.0.0/8`, with the third and fourth octets 0 and the second octet plus 8 at most 255.
