# PF-09 docker VM memory {#pf-09}

Help for item PF-09 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Low memory {#low}

It is enough to play. Running the automated verification (`sysfail verify`) in parallel needs more. On macOS, increase it with `colima start -p sysfail --memory <GB>`.
