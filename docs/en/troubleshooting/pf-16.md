# PF-16 Leftover containers {#pf-16}

Help for item PF-16 of `sysfail doctor`. doctor prints a one-line summary and the URL of this page.

## Current leftovers {#current}

Containers from an earlier game. They are cleaned up automatically on the next start. Run `sysfail stop` to remove them now.

## Leftovers with old labels {#legacy}

Containers from older versions are not removed automatically. Check them and remove them:

```bash
docker ps -a --filter label=sysfail
docker rm -f <container>
```

## A game from another state directory {#foreign}

A game from another state directory (`SYSFAIL_STATE_DIR`) is using the same docker. play does not clean it up and will not start until it ends. If it is no longer needed, run `sysfail stop` with that state directory.

## The check failed {#failed}

Check docker with `docker ps -a` and run doctor again. The game checks again when it starts.
