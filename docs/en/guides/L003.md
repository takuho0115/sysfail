# L003 The app keeps stopping

1. Check the service status on web01 (root)
   - If it is stopped, check whether it has been trying to restart repeatedly

2. Look in the logs for startup failure messages
   - Look for signs of write errors or insufficient space
   - Also pay attention if the logs appear corrupted

3. Check disk usage
   - Find which filesystem is full

4. Look for large files
   - Check for old files that are no longer needed

5. Check whether log files are still in use
   - Consider whether deleting them would actually reclaim space

## Why investigate this area?

A service that stops immediately after every restart is encountering a persistent failure during startup.
Reading the logs to identify that failure is an efficient first step.

## Common pitfalls

- Repeatedly trying to restart without reading the logs
- Taking action without understanding filesystem usage
- Failing to check whether deleting a file actually freed space
