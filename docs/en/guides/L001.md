# L001 The online shop is unavailable

1. Check the service status on web01 (root)
   - Distinguish between a stopped service and one that is running but not responding

2. If it is stopped, look through the logs for signs of how it exited
   - Pay attention to whether a signal terminated it
   - Read the messages and exit codes

3. Check whether port 80 really has no listener
   - Use network commands to check for an HTTP response

4. Check the configuration file
   - Look for syntax errors

5. Try starting the service manually
   - See whether the process can start normally

## Why investigate this area?

A page that will not load can have several causes. First, establish whether the service has actually stopped.
Checking its status before tracing what happened in the logs is an efficient way to investigate.

## Common pitfalls

- Running a start command before investigating the cause
- Stopping the investigation after reading the logs, without checking whether the same failure could recur
