# L018 The app stops responding every few minutes

1. On web01 (ops; use sudo for administrative operations), check what is being terminated and when
   - Look for forced termination records with `dmesg | tail`
   - Compare the process names and timestamps in those records

2. On web01 (ops), find the processes using the most memory
   - `ps -eo pid,rss,comm --sort=-rss | head`

3. Compare the same process's usage over time
   - Check RSS every few dozen seconds to see whether it keeps growing

4. Read the configuration of the process whose usage keeps growing
   - Under /etc/shopapp/, look for settings and comments about memory use

5. After changing the configuration and restarting, compare memory usage over time again

## Why investigate this area?

A service that goes down and comes back every few minutes, accompanied by recurring out-of-memory records, fits a pattern of memory growing until it reaches a limit and triggers forced termination.
The termination is a consequence; the cause lies with the process whose usage keeps growing. A single measurement cannot show growth, so watch the trend.

## Common pitfalls

- Treating the temporary improvement after a restart as a solution, even though the crash returns later
- Looking at ps only once and judging solely by the amount of memory used
- Assuming that the terminated process must also be the process causing the memory pressure
