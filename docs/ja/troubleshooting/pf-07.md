# PF-07 コンテナランタイムのバージョン {#pf-07}

`sysfail doctor` の PF-07 の項目の説明です。doctor は 1 行の要点とこのページの URL を出します。

## 脆弱性のある・古いランタイム {#denied}

runc・containerd は docker と一緒に更新されます。docker のパッケージを更新してください。

## バージョンを確認できない {#unconfirmed}

前提確認の表に拒否するバージョンが無いときや、バージョンを取得できないときに警告になります。ゲームは起動します。docker を最新に保っていれば、気にしなくてかまいません。
