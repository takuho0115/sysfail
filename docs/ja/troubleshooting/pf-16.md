# PF-16 残骸コンテナ {#pf-16}

`sysfail doctor` の PF-16 の項目の説明です。doctor は 1 行の要点とこのページの URL を出します。

## 現行の残骸 {#current}

前のゲームのコンテナです。次にゲームを起動したときに自動で片付きます。すぐ消したいときは `sysfail stop` を実行してください。

## 旧バージョンのラベルがある残骸 {#legacy}

古いバージョンで作られたコンテナは自動では消しません。中身を確かめてから削除してください。

```bash
docker ps -a --filter label=sysfail
docker rm -f <コンテナ名>
```

## 別の状態ディレクトリのゲーム {#foreign}

同じ docker を、別の状態ディレクトリ（環境変数 `SYSFAIL_STATE_DIR`）のゲームが使っています。play はこれを片付けず、そのゲームが終わるまで起動しません。不要なら、その状態ディレクトリを指定して `sysfail stop` を実行してください。

## 確認に失敗した {#failed}

docker の状態を `docker ps -a` で確かめてから、doctor をやり直してください。ゲームの起動時にも、もう一度確かめます。
