# PF-11 docker の接続先 {#pf-11}

`sysfail doctor` の PF-11 の項目の説明です。doctor は 1 行の要点とこのページの URL を出します。

## 接続先が遠隔 {#remote}

ゲームは、この端末のローカルの docker だけを操作します。環境変数 `DOCKER_HOST` を解除する（`unset DOCKER_HOST`）か、`docker context use default` でローカルに戻してください。

## 同じ機械と確かめられない（macOS） {#unverifiable}

docker の接続先が sysfail 専用の colima のソケットか、`colima ssh -p sysfail` が通るかを確かめてください。同じ VM であると確かめられない間は、隔離テストを合格にしません。
