## docker コマンドが見つからない {#missing}

ゲームは docker でレベル環境を作るため、docker コマンドが無いと起動できません。

- Linux・WSL2: ディストリビューションの手順で Docker Engine を入れます（例: Fedora なら `sudo dnf install docker-ce`、Ubuntu なら Docker の公式リポジトリから `docker-ce`）。
- macOS: colima と docker CLI を入れます（[macOS のインストール](https://takuho0115.github.io/sysfail/ja/install/macos/)）。

入れたあと、`docker --version` が動くか確かめてください。動かないときは、docker のある場所が PATH に入っているかを確かめます。
