# PF-10 動作保証の環境 {#pf-10}

`sysfail doctor` の PF-10 の項目の説明です。doctor は 1 行の要点とこのページの URL を出します。

## 保証の対象外の環境 {#unsupported}

動作を保証するのは Linux + Docker Engine と、WSL2 の中の Docker Engine です。Docker Desktop やその他の OS でも起動はしますが、動作は保証しません。保証外の環境では、プレイ中にディスクの空きを監視しません。docker のディスクの上限と、ホストの空き（10GB 以上）を自分で確かめてください。

## 環境を判別できない {#unknown}

OS や docker の種類を判別できませんでした。起動はしますが、保証の対象外として扱います。

## 確認していないカーネル（WSL2） {#kernel}

WSL2 では、確認済みのカーネルの一覧に無いカーネルでも起動します。動作は確かめていません。`wsl --update` で更新すると一覧のカーネルになることがあります。

## macOS（検証中・プレビュー） {#macos}

macOS は検証中で、保証の対象外です。確かめたのは darwin 版のビルド、macOS での単体テスト、install.sh までで、colima の上での実際のプレイはまだ確かめていません。ネットワークの間を中継するレベル（L052・L068）は、macOS では起動前に止めます。sysfail 専用の colima のプロファイルの作り方は [macOS のインストール](https://takuho0115.github.io/sysfail/ja/install/macos/) にあります。不具合は GitHub Issues の macOS 用テンプレートで知らせてください。

## macOS の保証の条件（P1〜P7） {#macos-conditions}

doctor が「満たさない条件」として示すものです。

- Apple Silicon（arm64）の Mac であること
- docker の接続先が colima のプロファイルのソケット（`~/.colima/<プロファイル>/docker.sock`）であること
- VM が vz・aarch64 で動いていること
- Mac のホームやその上位のディレクトリをマウントしていないこと（マウントは無しか、sysfail 専用の 1 つを読み取り専用で）
- VM に Mac のループバック以外から届かないこと（既定のネットワークのまま使う）
- VM のディスクが Mac の空きより小さいこと
- colima・Lima・VM のカーネルの組み合わせが、実機で確かめたものであること

## Docker Desktop {#desktop}

Docker Desktop は保証の対象外です。Docker Desktop の上では、隔離テストに使うコンテナを作りません。そのため、確認済みの範囲を超えたバージョンの docker では、隔離を確かめられません。Linux + Docker Engine か、macOS なら colima を使ってください。
