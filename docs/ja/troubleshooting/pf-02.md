# PF-02 docker デーモン {#pf-02}

`sysfail doctor` の PF-02 の項目の説明です。doctor は 1 行の要点とこのページの URL を出します。

## デーモンに接続できない {#down}

docker デーモンが動いていません。

- Linux・WSL2: `sudo systemctl start docker`（起動時に自動で上げるには `sudo systemctl enable docker`）
- macOS: `colima start -p sysfail`

## docker を操作する権限がない {#permission}

Linux では、利用者を docker グループに加えると sudo なしで docker を使えます。

```bash
sudo usermod -aG docker "$USER"
```

そのあと、ログインし直してください。docker グループの利用者は、実質的に root と同じ操作ができます。共用の機械では加える人を絞ってください。

## デーモンが応答しない {#no-response}

ほかの起動や片付けで docker が混んでいると、時間内に応答しないことがあります。並行する作業が終わってからやり直してください。繰り返すときは `docker info` が返ってくるか、`journalctl -u docker` に異常が出ていないかを確かめます。

## 状態を確認できない {#other}

`docker info` を実行し、表示されるエラーから原因を確かめてください。
