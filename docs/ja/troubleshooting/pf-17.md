# PF-17 隔離テスト（docker 脱出防止） {#pf-17}

`sysfail doctor` の PF-17 の項目の説明です。doctor は 1 行の要点とこのページの URL を出します。

## 隔離が破れている {#breached}

レベル環境の内部ネットワークから、外部やホストへ通信が届きました。この docker ではレベル環境を安全に閉じ込められないため、起動を止めます。docker Engine を確認済みのバージョンへ戻すか、修正版を待ってください。再現する手順が分かれば GitHub Issues に知らせてください。

## ホストの待ち受けに届く {#reached}

コンテナから、この端末で待ち受けているサービスに通信が届きました。docker はこの通信を制限しません。[PF-14 のファイアウォールの例](pf-14.md#firewall)で閉じてください。ゲームは起動します。

## 判定できない {#undetermined}

- 時間切れ: docker が混んでいます。並行する作業が終わってからやり直してください。
- イメージが無い: 隔離テストのイメージは初回の準備で作ります。一度ゲームを始めてから `sysfail doctor` をやり直してください。
- その他: `docker info` で docker の状態を確かめてからやり直してください。

## デーモン側で実行・観測できない {#daemon-side}

docker の状態を確かめてからやり直してください。macOS では colima の再起動（`colima restart -p sysfail`）と、sysfail 専用プロファイルの作り直しを試してください。
