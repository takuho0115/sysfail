# PF-12 ネットワークのアドレス範囲 {#pf-12}

`sysfail doctor` の PF-12 の項目の説明です。doctor は 1 行の要点とこのページの URL を出します。

## この端末の経路と重なる {#overlap}

ゲームは既定で `10.200.0.0` から始まるアドレス範囲を使います。この端末の LAN や VPN のアドレスと重なると、通信の行き先がぶつかり、どちらかに届かなくなります。環境変数 `SYSFAIL_SUBNET_BASE` で始まりのアドレスを変えてください。

```bash
export SYSFAIL_SUBNET_BASE=10.120.0.0
```

値は `10.0.0.0/8` の中で、第 3・第 4 オクテットが 0、第 2 オクテットに 8 を足して 255 以下になるものにします。
