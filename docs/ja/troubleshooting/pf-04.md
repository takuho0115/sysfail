# PF-04 docker Engine のバージョン {#pf-04}

`sysfail doctor` の PF-04 の項目の説明です。doctor は 1 行の要点とこのページの URL を出します。

## 下限より古い {#below-floor}

下限より古い docker Engine には、内部ネットワークから外の名前の問い合わせがホストへ転送される脆弱性（CVE-2024-29018）があります。doctor が示すバージョン以上へ更新してください。更新はディストリビューションのパッケージ管理（`dnf upgrade docker-ce` など）で行います。

## 脆弱性のあるバージョン {#denied}

このバージョンには、実行端末の外からレベル環境へ通信が届く恐れのある脆弱性があります。doctor が示す範囲（下限以上で、除外範囲に入らないもの）へ更新してください。

## バージョンを判別できない {#unparsable}

`docker version` の出力を確かめてください。開発用のビルドや独自のビルドでは、バージョンの形が違うことがあります。

## 確認済みの範囲より新しい {#newer}

前提確認の表で確認したのは、表にあるバージョンまでです。それより新しいバージョンは既知の問題が調べられていません。ゲームは起動し、起動の直前に隔離テスト（[PF-17](pf-17.md)）で隔離が保たれているかを確かめます。

## --accept-version で許可した {#accepted}

拒否されるバージョンを、利用者の指定で許可しています。表で拒否している理由（脆弱性の番号）を調べ、自分の環境が影響を受けないことを確かめてから使ってください。
