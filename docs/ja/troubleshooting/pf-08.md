# PF-08 docker データ領域の空き {#pf-08}

`sysfail doctor` の PF-08 の項目の説明です。doctor は 1 行の要点とこのページの URL を出します。

## 空きが少ない {#low}

レベルのイメージとコンテナに 10GB 以上の空きが要ります。使っていないイメージやコンテナを消すと空きが増えます。

```bash
docker system df
docker system prune
```

`docker system prune` は、止まっているコンテナと使っていないイメージ・ネットワークを消します。ほかの用途のものが消えないか、先に確かめてください。

## WSL2 のディスク {#wsl2}

WSL2 のディスクは Windows のドライブ上の vhdx ファイルです。vhdx の最大サイズが Windows のドライブの空きより大きいと、WSL の中では空いて見えても Windows 側が先に尽きます。`.wslconfig` の `defaultVhdSize` などで、最大サイズを Windows の空きより小さくしてください。

## macOS（colima）のディスク {#macos}

colima の VM のディスクと、それを置く Mac のボリュームの両方に空きが要ります。VM のディスクが Mac の空きより大きいと、VM が使い切る前に Mac が尽きます。sysfail 専用のプロファイルを、Mac の空きより小さいディスクで作り直してください（`colima delete -p sysfail` のあと `colima start -p sysfail --disk <GB>`）。
