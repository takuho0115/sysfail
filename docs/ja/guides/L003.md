# L003 アプリが停止する

1. web01（root）でサービスの状態を確認する
   - 停止しているか、再起動を繰り返していないかを見る

2. ログで起動の失敗メッセージを探す
   - 書き込みエラーやスペース不足の兆候を探す
   - ログが破損して見える場合も注目する

3. ディスク使用率を確認する
   - どこが満杯になっているか見つける

4. 大きなファイルを探す
   - 不要な古いファイルが残っていないか

5. 削除したログファイルをプロセスが開いたままにしていないか確認する
   - ファイルを削除したときに容量が解放されるかを考える

## なぜそこを疑うか

「再起動してもすぐ止まる」という症状は、起動時に毎回何かが失敗していることを示しています。
ログから、その失敗が何なのかを読むことが効率的です。

## つまずきやすい点

- ログを見ずに何度も再起動を試みること
- ファイルシステムの使用状況を知らずに対処すること
- 削除したファイルが本当に容量を解放しているか確認しないこと
