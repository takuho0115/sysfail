# L072 アップロードは成功と出るのに、ファイルが残らない

1. web01（ops、管理操作は sudo）で、アプリが本当に動いているかを確かめる
   - `systemctl status uploadapp` で稼働していることを見る
   - 「成功」と返るのにファイルが無いので、アプリの外側ではなく保存の段階を疑う

2. web01（ops）で、アプリを動かしているユーザーを確かめる
   - `ps -o user,uid,cmd -C python3` で実行ユーザーと数値の uid を見る
   - ユニットファイルの `User=` でも確認できる

3. web01（ops）で、保存先の所有者と権限を確かめる
   - `ls -ldn /srv/shared` で、名前ではなく数値の uid・gid とモードを見る
   - 手順 2 の uid と見比べ、そのユーザーが書き込めるかを判断する

4. 書き込めるようにしたら、web01（ops）から実際にアップロードして確かめる
   - `curl -s -X POST --data-binary @/etc/hostname http://localhost:8080/upload` のあと `ls -l /srv/shared`

## なぜそこを疑うか

エラーもログも無いのにファイルだけが無いときは、失敗がどこかで握りつぶされていると考えます。
保存の失敗でいちばん多いのは権限です。
ユーザー名は環境ごとに別の uid に割り当てられることがあるので、数値で見比べるのが確実です。

## つまずきやすい点

- 「成功」の応答を信じて、アプリの外側（Web サーバーやネットワーク）から調べ始めること
- ユーザー名だけを見て「合っている」と判断すること
- 書けないからといって 777 に広げること。誰でも書ける状態は別の問題を生む
