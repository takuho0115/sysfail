# L004 HTTPS でアクセスすると「安全ではない接続」と出る

1. toolbox（ops）で HTTPS 接続のエラーメッセージを確認する
   - エラーの種類を読む

2. web01（root）で証明書ファイルの場所を探す
   - nginx の設定ファイルから証明書のパスを確認する

3. 証明書の情報を確認する
   - ファイルが存在するか
   - 有効期限はいつまでか

4. 現在日時と証明書の有効期限を比較する
   - 有効期限内か期限切れか

5. 期限切れなら、新しい証明書を用意する
   - この環境でのツールや方法を確認する

6. 設定が正しいか確認してからサービスを再読み込みする
   - 設定に問題がないか
   - サービスが新しい証明書を使っているか

## なぜそこを疑うか

HTTPS 接続が失敗する原因は複数あります。
クライアント側のエラーメッセージから原因を絞り込み、サーバー側で状態を確認するのが効率的です。

## つまずきやすい点

- エラーメッセージを読まずに対応すること
- 設定を変更したあとでサービスを再読み込みするのを忘れること
- 証明書の配置と設定のパスのずれに気づかないこと
