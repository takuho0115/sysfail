# L018 アプリが数分おきに応答しなくなる

1. web01（ops、管理操作は sudo）で、何が・いつ落ちているかを確かめる
   - `dmesg | tail` で強制終了の記録を探す
   - 終了させられたプロセス名と時刻の並びを見る

2. web01（ops）で、メモリを多く使っているプロセスを探す
   - `ps -eo pid,rss,comm --sort=-rss | head`

3. 同じプロセスの使用量を時間をあけて比べる
   - 数十秒おきに RSS を見て、増え続けているかを確かめる

4. 増え続けているプロセスの設定ファイルを読む
   - /etc/shopapp/ の下で、メモリの使い方に関わる項目とコメントを探す

5. 設定を直して再起動したら、もう一度時間をあけて使用量を比べる

## なぜそこを疑うか

「数分おきに落ちては戻る」「メモリ不足の記録が定期的に並ぶ」のは、メモリ使用量が少しずつ増えて上限に届くたびに強制終了される典型です。
落とされたのは結果で、原因は増え続けているプロセスの側にあります。一点の値では増えているか分からないので、推移を見ます。

## つまずきやすい点

- 再起動で一時的に直ったのを解決と思うこと（しばらくするとまた落ちる）
- 一回だけ ps を見て、使用量の大きさだけで判断すること
- 強制終了されたプロセスと、メモリを消費している原因のプロセスを同じものと決めつけること
