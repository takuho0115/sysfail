# L001 ECサイトが表示されない

1. web01（root）でサービスの状態を確認する
   - 停止しているのか、応答しないのかを見分ける

2. 停止状態なら、終了の兆候をログから探す
   - シグナルで終了したかどうかに注目する
   - メッセージや終了コードを読む

3. ポート 80 で本当に待ち受けていないか確認する
   - ネットワークコマンドで HTTP の応答が返るか確かめる

4. 設定ファイルを確認する
   - 構文エラーがないか確かめる

5. 手動で起動してみる
   - プロセスが正常に開始できるか試す

## なぜそこを疑うか

「表示されない」という症状には複数の原因が考えられるため、まず「本当に止まっているのか」を見分ける必要があります。
状態を確認してから、ログで「何が起きたのか」を遡るのが効率的です。

## つまずきやすい点

- 原因を調べないまま起動コマンドを実行すること
- ログを読んだだけで対処を終え、同じ障害の再発を見落とすこと
