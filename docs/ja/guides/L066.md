# L066 商品の税率が古い

1. app01（ops、管理操作は sudo）で、現在の価格を確かめる
   - `curl -s 'http://127.0.0.1:8080/price?item=A'` を実行する

2. ソースを直して再ビルドできるかを確かめる
   - `bash /srv/src/legacyapp/build.sh` を実行し、失敗の理由を読む
   - 必要なコンパイラが手に入るのかどうかを見極める

3. 実行ファイルの中に税率がどう入っているかを調べる
   - 書き換える前に、元の実行ファイルを `cp -p` で legacyapp.orig として退避する
   - `strings -t d /opt/legacyapp/bin/legacyapp` や `grep -abo` で、税率らしい値とその位置を探す
   - `xxd -s <位置> -l 8` で、その位置のバイトを確かめる

4. 書き換えの手順を決める
   - 動いているプログラムのファイルには書き込めない（Text file busy）。サービスを止める時間をできるだけ短くする
   - サービスの停止・起動と、実行ファイルへの書き込みには `sudo` が要る
   - 書き換えたあとはサービスを起動し、価格をもう一度確かめる

## なぜそこを疑うか

ソースを直してもビルドできないなら、変えられるのは手元にある実行ファイルだけです。
税率のような定数は、実行ファイルの中に文字列や数値としてそのまま残っていることがよくあります。
まずビルドの失敗理由を読むと、なぜ作り直せないのかがはっきりし、別の道を探す判断がつきます。

## つまずきやすい点

- 退避を忘れて、元の実行ファイルを直接書き換えること。戻せなくなるうえ、完了条件も満たせません
- 書き換える値の長さを変えること。前後のバイトがずれてプログラムが壊れます
- 稼働中に書き込もうとして Text file busy で失敗し、原因が分からずに止まること
- 似た値が複数あるのに、位置を確かめずに最初の 1 つを書き換えること
