# L008 商品一覧のページだけ 502 エラーになる

1. web01（ops、管理操作は sudo）で、nginx のエラーログを見る
   - `sudo tail -n 5 /var/log/nginx/error.log` で、どのアドレスへの接続に失敗しているかを読む

2. nginx がどの名前に転送しているかを確かめる
   - /etc/nginx/ の設定で `proxy_pass` の宛先を探す

3. その名前が、どのアドレスに解決されるかを確かめる
   - web01（ops）で `getent hosts <名前>` を実行する
   - エラーログのアドレスと一致するか、そのアドレスが社内のサーバーのものかを見る

4. 名前解決を決めているファイルを読む
   - `cat /etc/hosts` で、手で編集された行を 1 行ずつ見直す
   - 転送先の行だけでなく、ほかの行にも打ち間違いがないかを確かめる

5. 直したら nginx を reload し、/products と / の両方を確かめる

## なぜそこを疑うか

502 Bad Gateway は、nginx 自身は動いていて、その先の転送先に届かないときに出ます。
トップページは表示されて /products だけ失敗するなら、/products の転送先だけが問題です。
直前にサーバーの設定ファイルを手で編集したという情報があり、エラーログに見覚えのないアドレスが出ているなら、名前とアドレスの対応を疑います。

## つまずきやすい点

- エラーログのアドレスを読まずに、転送先のサーバー（API 側）が落ちていると決めつけること
- 一番目立つ誤りだけ直して、同じファイルのほかの行の打ち間違いを見落とすこと
- 修正後に nginx を reload せず、古い解決結果のまま確かめてしまうこと
