# L020 すべてのページが「アクセス禁止」になる

1. web01（ops、管理操作は sudo）で nginx のエラーログを読む
   - `sudo tail -n 5 /var/log/nginx/error.log` で、403 の理由が書かれていないか

2. 設定から公開ディレクトリの場所を確かめる
   - `sudo nginx -t` で設定に誤りがないことも見ておく

3. 公開ファイルまでの途中のディレクトリの権限をまとめて見る
   - `namei -l /usr/share/nginx/html/index.html`
   - nginx のワーカーが動くユーザーで、各ディレクトリをたどれる（x）か、ファイルを読める（r）か

4. 権限を直したら、ページと CSS の両方が表示されるか確かめる

## なぜそこを疑うか

プロセスは動いていて全ページが 403 なら、nginx は要求を受けたうえで拒んでいます。
「権限を見直した」という直前の変更があり、ワーカーは root ではないユーザーで動くので、そのユーザーから見てファイルに届くかを疑います。

## つまずきやすい点

- 末端のファイルだけを見て、途中のディレクトリの x の欠けを見落とすこと
- sudo（管理者権限）で読めるので問題ないと判断すること（読むのはワーカーのユーザー）
- 安易に 777 にしてしまうこと（完了条件で禁止されている）
