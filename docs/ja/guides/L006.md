# L006 商品一覧が出ず「データベースエラー」と表示される

1. web01（ops、管理操作は sudo）で、アプリの稼働状態とログを確かめる
   - `systemctl status shopapp` で稼働状態を見る
   - `journalctl -u shopapp --no-pager | tail` で、DB に接続するときのエラーの種類を読む

2. アプリが DB の接続情報をどこから読んでいるかをたどる
   - `systemctl cat shopapp` でユニットが読み込む環境変数のファイルを探す
   - /etc/shopapp/ の設定から、接続先・ユーザー・パスワードを確認する

3. 設定の値で、手で DB に接続してみる
   - web01（ops）で `mysql -h db01 -u shop -p` を実行し、アプリと同じエラーになるか確かめる

4. 正しい値がどこに書かれているかを探す
   - アプリのディレクトリにある運用の引き継ぎメモ（README）を読む

5. 設定を直し、アプリを再起動して確かめる
   - web01（ops）で `curl -fs localhost:8080/health`

## なぜそこを疑うか

トップページは開くのに商品一覧だけがエラーなら、アプリは動いていて、その先の DB とのやりとりで失敗しています。
直前に DB 側で作業があったという情報もあるので、「DB 側で変わったもの」と「アプリが覚えている値」の食い違いを疑います。
ログのエラーが「接続できない」なのか「認証で拒否された」なのかで、ネットワークを見るか資格情報を見るかが分かれます。

## つまずきやすい点

- エラーの種類を読まずに、DB サーバーやネットワークを疑ってしまうこと
- 設定を直してもアプリを再起動しないと、古い値のまま動き続けること
- 手で接続して確かめる前に、推測で値を書き換えること
