# L010 アプリが起動しない

1. web01（ops、管理操作は sudo）で、アプリのユニットが起動できない理由を読む
   - `systemctl status shopapp`
   - `journalctl -u shopapp --no-pager | tail` で、何が足りないと出ているかを確かめる

2. ユニットが設定をどこから読んでいるかをたどる
   - `systemctl cat shopapp` で、読み込む環境変数のファイルを探す

3. そのファイルの中身と、周りのファイルを見比べる
   - `ls -la /etc/shopapp/` でファイルの大きさを見る
   - 見本のファイル（.example）があれば、必要な変数の一覧を確かめる
   - 値の手がかりになるファイルが同じディレクトリにないか探す

4. 必要な変数を設定してから再起動し、確かめる
   - toolbox（player）で `curl -i http://web01/` と `curl -i http://web01/status`

## なぜそこを疑うか

502 はアプリ側が応答していないことを示し、ユニットが起動に失敗しているなら、まず起動できない理由をログで読むのが近道です。
「前の環境から持ってきたはず」という話は、設定ファイルの中身が移されていない可能性を示しています。
ファイルが存在することと、中身が正しいことは別なので、大きさや中身まで確かめます。

## つまずきやすい点

- ファイルがあることだけ確かめて、中身が空であることに気づかないこと
- エラーに出た変数だけを足して、見本にあるほかの必要な変数を忘れること
- 値を推測で作ってしまうこと（手がかりのファイルから取る）
- 設定後に再起動を忘れること
